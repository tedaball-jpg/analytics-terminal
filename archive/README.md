# Archive

Not part of the Analytics Terminal app. Kept for the learning record, moved out of the
project root so the terminal's own code isn't mixed in with unrelated files.

- **`early_exercises/`** — standalone scripts from earlier in this learning project
  (a compound interest calculator, an AI-generated news briefing script). Neither is
  imported by the terminal app or covered by its tests.
- **`sample_outputs/`** — PNG charts saved by `portfolio.py`'s and `macro_dashboard.py`'s
  own `main()` functions when run as standalone scripts (`python portfolio.py`). These
  are not screenshots of the Streamlit app; see [`../screenshots/`](../screenshots/) for
  those.
